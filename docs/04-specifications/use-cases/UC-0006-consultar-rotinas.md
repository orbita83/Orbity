# [UC-0006] - Consultar rotinas

## 1. Identificação

| Campo | Descrição |
|---|---|
| **ID** | UC-0006 |
| **Nome** | Consultar rotinas |
| **Ator principal** | Estudante |
| **Objetivo** | Visualizar as rotinas cadastradas e os detalhes de cada rotina |

## 2. Contexto

Possibilita ao estudante consultar suas rotinas na tela **Rotinas** ("Seus hábitos, todos os dias"), buscar rotinas pelo campo de busca e abrir o detalhe de uma rotina, que apresenta nome, descrição e a lista de tarefas da rotina.

## 3. Pré-condições

- A tela de rotinas deve estar acessível pela barra de navegação.

## 4. Pós-condições

- As rotinas cadastradas devem ser exibidas na lista.
- Ao selecionar uma rotina, o detalhe com suas tarefas deve ser apresentado.
