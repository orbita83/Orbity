# [UC-0013] - Consultar conquistas

## 1. Identificação

| Campo | Descrição |
|---|---|
| **ID** | UC-0013 |
| **Nome** | Consultar conquistas |
| **Ator principal** | Estudante |
| **Objetivo** | Visualizar as conquistas, consultar seus detalhes e compartilhá-las |

## 2. Contexto

As conquistas são acessadas pelo atalho do painel deslizante da tela inicial ou pela opção **Conquistas** do perfil. A tela apresenta a lista de conquistas com campo de busca e, ao selecionar uma conquista, exibe seu critério, o estado de conclusão, a data de desbloqueio e a ação **Compartilhar**. As conquistas são alcançadas conforme [RN-0005](../../02-requirements/business-rules/RN-0005.md).

## 3. Pré-condições

- O painel deslizante da tela inicial ou a tela de perfil deve estar acessível.

## 4. Pós-condições

- A lista de conquistas deve ser exibida.
- Ao selecionar uma conquista, seus detalhes devem ser apresentados.
