# [UC-0012] - Explorar constelação

## 1. Identificação

| Campo | Descrição |
|---|---|
| **ID** | UC-0012 |
| **Nome** | Explorar constelação |
| **Ator principal** | Estudante |
| **Objetivo** | Visualizar as estrelas conquistadas e consultar os detalhes de cada estrela |

## 2. Contexto

A tela **Cosmos** ("Seu esforço, suas estrelas") apresenta a constelação do estudante e a quantidade de estrelas conquistadas. Ao tocar em uma estrela, o estudante consulta seu nome e uma curiosidade astronômica.

## 3. Pré-condições

- A aba **Cosmos** deve estar acessível pela barra de navegação.

## 4. Pós-condições

- A constelação deve refletir o progresso da sequência ([RN-0003](../../02-requirements/business-rules/RN-0003.md)).
- Ao tocar em uma estrela, os detalhes da estrela devem ser exibidos.
