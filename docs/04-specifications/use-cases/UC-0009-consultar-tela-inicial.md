# [UC-0009] - Consultar tela inicial

## 1. Identificação

| Campo | Descrição |
|---|---|
| **ID** | UC-0009 |
| **Nome** | Consultar tela inicial |
| **Ator principal** | Estudante |
| **Objetivo** | Acompanhar a sequência de estudos e acessar o painel da tela inicial |

## 2. Contexto

A tela inicial apresenta o visualizador de sequência. Com um movimento de deslizar (*swipe*), o estudante abre o painel que reúne o acesso ao modo foco (único ponto de acesso a essa funcionalidade), a barra de progresso, que permanece visível, e o atalho para **Conquistas**.

## 3. Pré-condições

- O aplicativo deve estar em execução, com a aba **Início** acessível na barra de navegação.

## 4. Pós-condições

- O visualizador de sequência deve estar visível.
- O painel com modo foco, progresso e atalho para conquistas deve estar disponível ao estudante.
