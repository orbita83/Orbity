# [UC-0003] - Editar tarefa

## 1. Identificação

| Campo | Descrição |
|---|---|
| **ID** | UC-0003 |
| **Nome** | Editar tarefa |
| **Ator principal** | Estudante |
| **Objetivo** | Modificar as informações cadastrais ou de agendamento de uma tarefa existente |

## 2. Contexto

Permite ao estudante atualizar dados de tarefas previamente registradas, como título, descrição, prioridade e horários de agendamento. Essa flexibilidade garante que a lista de afazeres reflita as mudanças e reprogramações da rotina acadêmica do estudante.

## 3. Pré-condições

- Deve existir ao menos uma tarefa cadastrada no sistema.
- A tarefa desejada deve estar acessível para edição a partir da listagem ou do menu de opções.

## 4. Pós-condições

- As informações atualizadas da tarefa devem estar persistidas e refletidas na interface do aplicativo.
- O histórico e os vínculos existentes da tarefa (com rotinas ou sessões) devem permanecer consistentes.
