# [UC-0014] - Consultar perfil

## 1. Identificação

| Campo | Descrição |
|---|---|
| **ID** | UC-0014 |
| **Nome** | Consultar perfil |
| **Ator principal** | Estudante |
| **Objetivo** | Consultar as métricas de estudo e acessar as opções do perfil |

## 2. Contexto

A tela **Meu perfil** apresenta o nome do estudante e as métricas de dias de sequência, conquistas adquiridas e horas de estudos completos, além das opções **Conquistas**, **Categorias** e **Configurações**.

*Ponto pendente de refinamento:* as telas de Categorias e Configurações não estão representadas no protótipo.

## 3. Pré-condições

- A aba **Perfil** deve estar acessível pela barra de navegação.

## 4. Pós-condições

- As métricas do estudante devem ser exibidas.
- As opções do perfil devem estar disponíveis para navegação.
