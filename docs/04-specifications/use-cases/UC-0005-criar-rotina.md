# [UC-0005] - Criar rotina

## 1. Identificação

| Campo | Descrição |
|---|---|
| **ID** | UC-0005 |
| **Nome** | Criar rotina |
| **Ator principal** | Estudante |
| **Objetivo** | Cadastrar uma rotina de estudos com tarefas e dias da semana |

## 2. Contexto

Permite ao estudante criar uma rotina a partir da ação **+ Nova rotina**, informando nome, descrição opcional, dias da semana, tarefas da rotina e categoria opcional.

## 3. Pré-condições

- A tela de rotinas deve estar acessível pela barra de navegação.

## 4. Pós-condições

- A nova rotina deve estar registrada e visível na lista de rotinas.
- As tarefas e os dias da semana definidos devem permanecer vinculados à rotina.
