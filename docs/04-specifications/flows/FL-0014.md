# [FL-0014] - Consulta do perfil

## 1. Contexto

**Finalidade do fluxo:** Apresentar as métricas do estudante e as opções do perfil.

**Objetivo do ator:** Acompanhar a própria evolução e acessar as opções do perfil.

## 2. Fluxo principal

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 1 | Estudante | Acessa a aba **Perfil** na barra de navegação. |
| 2 | Sistema | Exibe a tela **Meu perfil** com o nome do estudante, as métricas de dias de sequência, conquistas adquiridas e horas de estudos completos, e as opções **Conquistas**, **Categorias** e **Configurações**. |
| 3 | Estudante | Seleciona uma das opções. |
| 4 | Sistema | Direciona o estudante para a seção correspondente. |

## 3. Fluxos alternativos

### 3a. Acesso às conquistas

**Ponto de desvio:** passo 3 do fluxo principal, quando o estudante seleciona **Conquistas**.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 3a.1 | Estudante | Seleciona **Conquistas**. |

**Resultado:** O fluxo continua em [FL-0013](FL-0013.md).

## 4. Fluxos de exceção

**Não se aplica.**

*Ponto pendente de refinamento:* as telas de **Categorias** e **Configurações** não estão representadas no protótipo.
