# [FL-0016] - Notificação e reconciliação de tarefas agendadas

## 1. Contexto

**Finalidade do fluxo:** Agendar, atualizar, cancelar, reconciliar e exibir lembretes locais para tarefas avulsas com data e horário de início futuros.

**Objetivo do ator:** Ser lembrado de forma acolhedora quando uma tarefa agendada começa e abrir diretamente a lista de tarefas ao tocar na notificação.

## 2. Fluxo principal

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 1 | Estudante | Cria ou edita uma tarefa avulsa informando título, data de início e horário de início no futuro ([FL-0001](FL-0001.md)). |
| 2 | Sistema | Salva a tarefa no armazenamento local e verifica a permissão de notificações. |
| 3 | Sistema | Agenda o lembrete local `task-reminder:<id>` para o instante de início com título e mensagem acolhedores ([RN-0011](../../02-requirements/business-rules/RN-0011.md)). |
| 4 | Sistema | No horário agendado, exibe a notificação local no aparelho. |
| 5 | Estudante | Toca na notificação exibida. |
| 6 | Sistema | Abre o aplicativo e navega para a aba **Tarefas**. |

## 3. Fluxos alternativos

### 3a. Atualização de data, horário ou título da tarefa

**Ponto de desvio:** passo 1 do fluxo principal, quando o estudante edita uma tarefa já existente.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 3a.1 | Estudante | Altera a data de início, o horário de início ou o título da tarefa para um horário futuro e salva. |
| 3a.2 | Sistema | Substitui o lembrete `task-reminder:<id>` com os novos dados e horário. |

**Resultado:** O lembrete passa a disparar no novo horário configurado.

### 3b. Remoção do agendamento, conclusão ou exclusão da tarefa

**Ponto de desvio:** após o passo 3 do fluxo principal.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 3b.1 | Estudante | Remove a data ou o horário de início na edição, marca a tarefa como concluída ([FL-0003](FL-0003.md)) ou exclui a tarefa ([FL-0004](FL-0004.md)). |
| 3b.2 | Sistema | Cancela o lembrete `task-reminder:<id>` no serviço de notificações. |

**Resultado:** Nenhum aviso é disparado para a tarefa concluída, excluída ou sem horário.

### 3c. Reabertura de tarefa concluída com horário futuro

**Ponto de desvio:** após uma tarefa agendada ter sido concluída ([FL-0003](FL-0003.md)).

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 3c.1 | Estudante | Desmarca a tarefa concluída enquanto sua data e horário de início ainda estão no futuro. |
| 3c.2 | Sistema | Volta a tarefa para pendente e reagenda o lembrete `task-reminder:<id>`. |

**Resultado:** O lembrete volta a ficar ativo para o horário de início da tarefa.

### 3d. Reconciliação ao abrir ou recarregar a aba Tarefas

**Ponto de desvio:** quando o estudante acessa ou retorna à aba **Tarefas** ([FL-0002](FL-0002.md)).

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 3d.1 | Sistema | Consulta as tarefas avulsas pendentes salvas e os lembretes `task-reminder:*` agendados no serviço de notificações. |
| 3d.2 | Sistema | Cancela lembretes órfãos e agenda ou atualiza os lembretes das tarefas abertas cujo horário de início seja futuro ([RN-0011](../../02-requirements/business-rules/RN-0011.md)). |

**Resultado:** Os lembretes do sistema operacional permanecem sincronizados com as tarefas salvas.

## 4. Fluxos de exceção

### 4a. Permissão de notificações negada

**Ponto de desvio:** passo 2 do fluxo principal.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 4a.1 | Sistema | Identifica que a permissão de notificações não foi concedida. |
| 4a.2 | Sistema | Mantém a tarefa salva normalmente e exibe uma indicação informativa e não bloqueante informando como ativar as notificações nas configurações do aparelho ([EC-0010](../edge-cases/EC-0010-lembrete-tarefa-sem-permissao-ou-horario-passado.md)). |

**Resultado:** A tarefa é criada ou atualizada sem bloqueio e sem agendamento nativo até que a permissão seja concedida.

### 4b. Horário de início no passado ou ausente

**Ponto de desvio:** passo 2 do fluxo principal ou passo 3c.1.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 4b.1 | Sistema | Verifica que a tarefa não possui data e horário de início completos ou que o instante configurado já passou ([EC-0010](../edge-cases/EC-0010-lembrete-tarefa-sem-permissao-ou-horario-passado.md)). |
| 4b.2 | Sistema | Salva a tarefa normalmente e não agenda lembrete (cancelando eventual lembrete anterior na edição). |

**Resultado:** A tarefa é mantida na lista sem disparo de notificação retroativa.
