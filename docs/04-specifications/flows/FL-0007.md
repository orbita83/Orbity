# [FL-0007] - Edição de rotina

## 1. Contexto

**Finalidade do fluxo:** Permitir alterar as informações de uma rotina existente.

**Objetivo do ator:** Manter a rotina atualizada.

## 2. Fluxo principal

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 1 | Estudante | No detalhe da rotina, aciona **Editar**. |
| 2 | Sistema | Exibe a edição da rotina com suas informações atuais. |
| 3 | Estudante | Altera as informações desejadas e confirma a edição. |
| 4 | Sistema | Registra as alterações e exibe o detalhe da rotina atualizado. |

## 3. Fluxos alternativos

**Não se aplica.**

## 4. Fluxos de exceção

**Não se aplica.**

*Ponto pendente de refinamento:* a tela de edição não está representada no protótipo; os campos editáveis e a ação de confirmação devem ser definidos.
