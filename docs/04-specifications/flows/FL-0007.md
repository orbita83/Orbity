# [FL-0007] - Edição de rotina

## 1. Contexto

**Finalidade do fluxo:** Permitir alterar as informações de uma rotina existente.

**Objetivo do ator:** Manter a rotina atualizada.

## 2. Fluxo principal

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 1 | Estudante | No detalhe da rotina, aciona **Editar**. |
| 2 | Sistema | Exibe **Editar rotina** com as informações atuais: nome, ícone, descrição, dias da semana e tarefas. |
| 3 | Estudante | Altera as informações desejadas (inclusive adiciona, remove ou reordena tarefas) e aciona **Salvar alterações**. |
| 4 | Sistema | Registra as alterações e exibe **Rotina atualizada!**. |
| 5 | Estudante | Aciona **Ver rotina**. |
| 6 | Sistema | Exibe o detalhe da rotina atualizado. |

## 3. Fluxos alternativos

**3a. Sair sem salvar, sem alterações**

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 3a.1 | Estudante | Aciona **Voltar sem salvar**. |
| 3a.2 | Sistema | Exibe o detalhe da rotina, sem mudanças. |

**3b. Sair sem salvar, com alterações**

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 3b.1 | Estudante | Aciona **Voltar sem salvar** depois de alterar algo. |
| 3b.2 | Sistema | Pergunta **Descartar alterações?**, com **Continuar editando** em destaque. |
| 3b.3 | Estudante | Aciona **Continuar editando** e volta ao passo 3 com o que já digitou, ou aciona **Descartar alterações** e o sistema exibe o detalhe da rotina como estava. |

**1a. Rotina sem tarefas**

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 1a.1 | Estudante | No estado vazio do detalhe ("Nenhuma tarefa nesta rotina"), aciona **Adicionar tarefas**. |
| 1a.2 | Sistema | Segue no passo 2. |

## 4. Fluxos de exceção

**3c. Nome vazio ou nenhum dia escolhido**

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 3c.1 | Sistema | Mostra as mesmas mensagens da criação ("Dê um nome para a rotina." e "Escolha pelo menos um dia."), sem perder o que foi digitado. |

**4a. Falha ao salvar**

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 4a.1 | Sistema | Mostra o aviso com ícone e texto, mantém o formulário preenchido e permite tentar de novo. |

As regras de marcação e conclusão ao editar estão no [UC-0007](../use-cases/UC-0007-editar-rotina.md).
