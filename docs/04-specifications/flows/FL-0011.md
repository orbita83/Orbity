# [FL-0011] - Atualização automática da sequência

## 1. Contexto

**Finalidade do fluxo:** Atualizar a sequência de estudos sempre que uma tarefa ou rotina for concluída.

**Objetivo do ator:** Refletir automaticamente a constância do estudante na sequência e na constelação.

## 2. Fluxo principal

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 1 | Sistema | Recebe o registro de conclusão de uma tarefa ([FL-0003](FL-0003.md)) ou rotina ([FL-0008](FL-0008.md)). |
| 2 | Sistema | Verifica se a condição de aumento da sequência foi satisfeita ([RN-0002](../../02-requirements/business-rules/RN-0002.md)). |
| 3 | Sistema | Registra o dia local da conclusão; a sequência é recalculada na leitura ([RF-0014](../../02-requirements/functional/RF-0014.md), [RF-0015](../../02-requirements/functional/RF-0015.md)). |
| 4 | Sistema | Faz a constelação progredir junto com a sequência ([RN-0003](../../02-requirements/business-rules/RN-0003.md)). |
| 5 | Sistema | Verifica se alguma conquista foi alcançada ([RN-0005](../../02-requirements/business-rules/RN-0005.md)). |

## 3. Fluxos alternativos

### 2a. Condição de aumento ainda não satisfeita

**Ponto de desvio:** passo 2 do fluxo principal, quando a conclusão é de uma tarefa que pertence a uma rotina, que não conta sozinha ([RN-0002](../../02-requirements/business-rules/RN-0002.md)).

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 2a.1 | Sistema | Registra a conclusão sem registrar o dia para a sequência. O [EC-0003](../edge-cases/EC-0003-conclusao-parcial-entre-rotina-e-tarefa-avulsa.md) foi substituído pela RN-0002. |

**Resultado:** O fluxo é encerrado.

### 2b. Dia já registrado

**Ponto de desvio:** passo 2 do fluxo principal, quando o dia local já foi registrado.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 2b.1 | Sistema | Registra a conclusão; o dia continua registrado uma vez só e a sequência não sobe de novo ([EC-0004](../edge-cases/EC-0004-multiplas-conclusoes-no-mesmo-dia.md)). |

**Resultado:** O fluxo é encerrado.

> **Entrega parcial (2026-11-14):** o design [`tela-inicial-base.md`](../../designs/tela-inicial-base.md) entrega os passos 1 a 3. A constelação (passo 4) e as conquistas (passo 5) não são entregues nessa mudança.

## 4. Fluxos de exceção

**Não se aplica.**
