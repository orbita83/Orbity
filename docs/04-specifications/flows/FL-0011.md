# [FL-0011] - Atualização automática da sequência

## 1. Contexto

**Finalidade do fluxo:** Atualizar a sequência de estudos sempre que uma tarefa ou rotina for concluída.

**Objetivo do ator:** Refletir automaticamente a constância do estudante na sequência e na constelação.

## 2. Fluxo principal

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 1 | Sistema | Recebe o registro de conclusão de uma tarefa ([FL-0003](FL-0003.md)) ou rotina ([FL-0008](FL-0008.md)). |
| 2 | Sistema | Verifica se a condição de aumento da sequência foi satisfeita ([RN-0002](../../02-requirements/business-rules/RN-0002.md)). |
| 3 | Sistema | Incrementa o contador de sequência. |
| 4 | Sistema | Faz a constelação progredir junto com a sequência ([RN-0003](../../02-requirements/business-rules/RN-0003.md)). |
| 5 | Sistema | Verifica se alguma conquista foi alcançada ([RN-0005](../../02-requirements/business-rules/RN-0005.md)). |

## 3. Fluxos alternativos

### 2a. Condição de aumento ainda não satisfeita

**Ponto de desvio:** passo 2 do fluxo principal, quando a conclusão não satisfaz a condição de aumento.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 2a.1 | Sistema | Registra a conclusão sem alterar o contador de sequência ([EC-0003](../edge-cases/EC-0003-conclusao-parcial-entre-rotina-e-tarefa-avulsa.md)). |

**Resultado:** O fluxo é encerrado.

### 2b. Sequência já incrementada no dia

**Ponto de desvio:** passo 2 do fluxo principal, quando o contador de sequência já foi incrementado no dia.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 2b.1 | Sistema | Registra a conclusão sem novo incremento da sequência ([EC-0004](../edge-cases/EC-0004-multiplas-conclusoes-no-mesmo-dia.md)). |

**Resultado:** O fluxo é encerrado.

## 4. Fluxos de exceção

**Não se aplica.**
