# [FL-0008] - Conclusão de rotina

## 1. Contexto

**Finalidade do fluxo:** Registrar a conclusão de uma rotina e de suas tarefas.

**Objetivo do ator:** Indicar que a rotina foi realizada.

## 2. Fluxo principal

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 1 | Estudante | Abre o detalhe de uma rotina ([FL-0006](FL-0006.md)). |
| 2 | Estudante | Aciona **Marcar como concluída**. |
| 3 | Sistema | Marca automaticamente todas as tarefas da rotina como concluídas ([RN-0004](../../02-requirements/business-rules/RN-0004.md)), exibindo-as marcadas e riscadas. |
| 4 | Sistema | Substitui o botão **Marcar como concluída** por **Desmarcar todos**. |
| 5 | Sistema | Aciona a atualização automática da sequência de estudos ([FL-0011](FL-0011.md)). |

## 3. Fluxos alternativos

### 2a. Marcação individual de tarefas da rotina

**Ponto de desvio:** passo 2 do fluxo principal, quando o estudante marca tarefas da rotina individualmente.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 2a.1 | Estudante | Marca uma ou mais tarefas da lista **Tarefas da rotina**. |
| 2a.2 | Sistema | Registra as tarefas marcadas como concluídas. |

**Resultado:** O fluxo retorna ao passo 2 do fluxo principal. Ao concluir a rotina, aplica-se [EC-0005](../edge-cases/EC-0005-conclusao-rotina-com-tarefas-ja-concluidas.md).

### 2b. Desmarcar todas as tarefas

**Ponto de desvio:** passo 2 do fluxo principal, quando a rotina já está concluída e o estudante aciona **Desmarcar todos**.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 2b.1 | Estudante | Aciona **Desmarcar todos**. |
| 2b.2 | Sistema | Desmarca todas as tarefas da rotina e volta a exibir o botão **Marcar como concluída**. |

**Resultado:** O fluxo é encerrado.

## 4. Fluxos de exceção

**Não se aplica.**
