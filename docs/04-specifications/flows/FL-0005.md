# [FL-0005] - Criação de rotina

## 1. Contexto

**Finalidade do fluxo:** Registrar uma nova rotina de estudos.

**Objetivo do ator:** Criar uma rotina com tarefas e dias da semana definidos.

## 2. Fluxo principal

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 1 | Estudante | Acessa a aba **Rotinas** na barra de navegação. |
| 2 | Sistema | Exibe a lista de rotinas com a ação **+ Nova rotina**. |
| 3 | Estudante | Aciona **+ Nova rotina**. |
| 4 | Sistema | Exibe o formulário **Nova Rotina** com os campos nome da rotina, descrição (opcional), dias da semana, lista de tarefas com a ação **+ Adicionar tarefa** e seleção de categoria (opcional). |
| 5 | Estudante | Informa o nome da rotina. |
| 6 | Estudante | Seleciona os dias da semana da rotina. |
| 7 | Estudante | Aciona **+ Adicionar tarefa** e adiciona as tarefas da rotina. |
| 8 | Sistema | Exibe as tarefas adicionadas em lista numerada. |
| 9 | Estudante | Aciona **Criar rotina**. |
| 10 | Sistema | Registra a rotina e a apresenta na lista de rotinas. |

## 3. Fluxos alternativos

### 8a. Reordenação das tarefas da rotina

**Ponto de desvio:** passo 8 do fluxo principal, quando o estudante deseja alterar a ordem das tarefas.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 8a.1 | Estudante | Arrasta uma tarefa pela alça de arraste até a nova posição. |
| 8a.2 | Sistema | Atualiza a ordem das tarefas na lista. |

**Resultado:** O fluxo retorna ao passo 9 do fluxo principal.

### 8b. Preenchimento de campos opcionais

**Ponto de desvio:** passo 8 do fluxo principal, quando o estudante deseja informar uma descrição ou uma categoria.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 8b.1 | Estudante | Informa a descrição da rotina. |
| 8b.2 | Estudante | Aciona a seleção de categoria e escolhe uma categoria. |

**Resultado:** O fluxo retorna ao passo 9 do fluxo principal.

## 4. Fluxos de exceção

**Não se aplica.**

*Ponto pendente de refinamento:* o protótipo não define se **+ Adicionar tarefa** cria uma nova tarefa ou associa uma tarefa existente, nem as opções do menu de cada tarefa da lista.
