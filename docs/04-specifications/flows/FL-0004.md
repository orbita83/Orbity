# [FL-0004] - Seleção múltipla e ações contextuais de tarefas

## 1. Contexto

**Finalidade do fluxo:** Permitir aplicar ações a uma ou mais tarefas selecionadas.

**Objetivo do ator:** Fixar, marcar, desmarcar ou excluir tarefas de forma rápida.

## 2. Fluxo principal

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 1 | Estudante | Na lista de tarefas, pressiona e segura (*long-press*) uma tarefa. |
| 2 | Sistema | Ativa o modo de seleção: marca a tarefa como selecionada, exibe no cabeçalho a quantidade de itens selecionados (por exemplo, "1 item selecionado"), oculta a barra de navegação e exibe a barra de ações contextuais com **Fixar**, **Marcar todas** e **Excluir (n)**. |
| 3 | Estudante | Toca em outras tarefas para incluí-las ou removê-las da seleção. |
| 4 | Sistema | Atualiza a quantidade de itens selecionados no cabeçalho e no rótulo **Excluir (n)**. |
| 5 | Estudante | Aciona **Excluir (n)**. |
| 6 | Sistema | Exclui as tarefas selecionadas e as remove da lista. |
| 7 | Sistema | Encerra o modo de seleção e volta a exibir a barra de navegação. |

## 3. Fluxos alternativos

### 5a. Fixar tarefas selecionadas

**Ponto de desvio:** passo 5 do fluxo principal, quando o estudante aciona **Fixar**.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 5a.1 | Estudante | Aciona **Fixar**. |
| 5a.2 | Sistema | Fixa as tarefas selecionadas. |

**Resultado:** O fluxo retorna ao passo 7 do fluxo principal.

### 5b. Marcar ou desmarcar todas as tarefas

**Ponto de desvio:** passo 5 do fluxo principal, quando o estudante aciona **Marcar todas**.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 5b.1 | Estudante | Aciona **Marcar todas**. |
| 5b.2 | Sistema | Marca todas as tarefas como concluídas ou, quando já estiverem marcadas, desmarca-as, e aciona a atualização automática da sequência de estudos ([FL-0011](FL-0011.md)). |

**Resultado:** O fluxo retorna ao passo 7 do fluxo principal.

## 4. Fluxos de exceção

### 5c. Exclusão de tarefa vinculada a sessão ativa do modo foco

**Ponto de desvio:** passo 5 do fluxo principal, quando alguma tarefa selecionada estiver vinculada a uma sessão ativa do modo foco.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 5c.1 | Sistema | Aplica o tratamento definido em [EC-0008](../edge-cases/EC-0008-alteracao-tarefa-ou-rotina-vinculada-ao-modo-foco.md), sem manter uma sessão ativa sem tarefa ou rotina vinculada. |

**Resultado:** O fluxo retorna ao passo 7 do fluxo principal.

*Ponto pendente de refinamento:* o protótipo não define o efeito visual de uma tarefa fixada nem se a exclusão exige confirmação; também deve ser confirmado se **Marcar todas** atua sobre a conclusão das tarefas (interpretação adotada neste fluxo) ou sobre a seleção de todos os itens da lista.
