# [FL-0003] - Conclusão e desmarcação de tarefa

## 1. Contexto

**Finalidade do fluxo:** Registrar a conclusão de uma tarefa ou desfazer essa marcação.

**Objetivo do ator:** Indicar quais tarefas já foram realizadas.

## 2. Fluxo principal

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 1 | Estudante | Acessa a lista de tarefas. |
| 2 | Estudante | Marca uma tarefa pendente como concluída. |
| 3 | Sistema | Registra a tarefa como concluída e atualiza sua apresentação na lista. |
| 4 | Sistema | Aciona a atualização automática da sequência de estudos ([FL-0011](FL-0011.md)). |

## 3. Fluxos alternativos

### 2a. Desmarcação de tarefa concluída

**Ponto de desvio:** passo 2 do fluxo principal, quando o estudante desmarca uma tarefa já concluída.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 2a.1 | Estudante | Desmarca a tarefa concluída. |
| 2a.2 | Sistema | Retorna a tarefa ao estado pendente e atualiza sua apresentação na lista. |

**Resultado:** O fluxo é encerrado. Quando a tarefa pertencer a uma rotina concluída, aplica-se [EC-0006](../edge-cases/EC-0006-desmarcar-tarefa-associada-apos-conclusao-da-rotina.md).

## 4. Fluxos de exceção

**Não se aplica.**
