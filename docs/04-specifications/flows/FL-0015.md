# [FL-0015] - Gerenciamento de categorias

## 1. Contexto

**Finalidade do fluxo:** Permitir que o estudante mantenha a lista de categorias de estudo.

**Objetivo do ator:** Ter categorias que combinem com o que ele estuda.

## 2. Fluxo principal

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 1 | Estudante | Seleciona **Categorias** na tela **Meu perfil** ([FL-0014](FL-0014.md)). |
| 2 | Sistema | Exibe a lista de categorias, com o ícone e o nome de cada uma. |
| 3 | Estudante | Aciona a criação de uma categoria. |
| 4 | Sistema | Solicita o nome e o ícone. |
| 5 | Estudante | Informa o nome, escolhe um ícone e confirma. |
| 6 | Sistema | Valida o nome ([RN-0008](../../02-requirements/business-rules/RN-0008.md)) e o ícone, salva a categoria e a exibe na lista. |

## 3. Fluxos alternativos

### 3a. Renomear categoria

**Ponto de desvio:** passo 3 do fluxo principal.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 3a.1 | Estudante | Escolhe uma categoria e aciona a edição do nome. |
| 3a.2 | Sistema | Valida o novo nome, salva e atualiza a lista. |

**Resultado:** A categoria mostra o novo nome em Tarefas e Rotinas.

### 3b. Trocar o ícone

**Ponto de desvio:** passo 3 do fluxo principal.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 3b.1 | Estudante | Escolhe uma categoria e aciona a troca de ícone. |
| 3b.2 | Estudante | Seleciona um ícone da lista. |
| 3b.3 | Sistema | Salva o ícone e atualiza a lista. |

**Resultado:** A categoria mostra o novo ícone em Tarefas e Rotinas.

### 3c. Excluir categoria

**Ponto de desvio:** passo 3 do fluxo principal.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 3c.1 | Estudante | Escolhe uma categoria e aciona a exclusão. |
| 3c.2 | Sistema | Pede a confirmação da exclusão. |
| 3c.3 | Estudante | Confirma. |
| 3c.4 | Sistema | Exclui a categoria e aplica [RN-0009](../../02-requirements/business-rules/RN-0009.md) às tarefas e rotinas que a usavam. |

**Resultado:** A categoria sai da lista, e as tarefas e rotinas continuam cadastradas ([EC-0009](../edge-cases/EC-0009-exclusao-categoria-em-uso.md)).

## 4. Fluxos de exceção

### 4a. Nome inválido ou repetido

**Ponto de desvio:** passo 6 do fluxo principal e passo 3a.2.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 4a.1 | Sistema | Informa o que corrigir (nome vazio, acima de 24 caracteres ou já existente) e mantém o que o estudante digitou. |

**Resultado:** Nada é salvo até o estudante corrigir o nome.

### 4b. Falha ao salvar

**Ponto de desvio:** passos 6, 3a.2, 3b.3 e 3c.4.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 4b.1 | Sistema | Informa que não foi possível salvar e permite tentar de novo. |

**Resultado:** As categorias, as tarefas e as rotinas permanecem como estavam.
