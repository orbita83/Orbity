# [FL-0013] - Consulta e compartilhamento de conquistas

## 1. Contexto

**Finalidade do fluxo:** Apresentar as conquistas do estudante e seus detalhes.

**Objetivo do ator:** Consultar conquistas e compartilhar uma conquista alcançada.

## 2. Fluxo principal

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 1 | Estudante | Aciona o atalho **Conquistas** no painel deslizante da tela inicial. |
| 2 | Sistema | Exibe a tela **Conquistas** com campo de busca e a lista de conquistas. |
| 3 | Estudante | Seleciona uma conquista. |
| 4 | Sistema | Exibe os detalhes da conquista, com nome, critério (por exemplo, "Conclua sua primeira sessão"), estado **Conquista concluída**, data de desbloqueio e a ação **Compartilhar**. |
| 5 | Estudante | Aciona **Compartilhar**. |
| 6 | Sistema | Disponibiliza o compartilhamento da conquista. |

## 3. Fluxos alternativos

### 1a. Acesso pelo perfil

**Ponto de desvio:** passo 1 do fluxo principal, quando o estudante acessa as conquistas pela tela de perfil.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 1a.1 | Estudante | Na tela **Meu perfil**, aciona a opção **Conquistas**. |

**Resultado:** O fluxo retorna ao passo 2 do fluxo principal.

### 3a. Busca de conquistas

**Ponto de desvio:** passo 3 do fluxo principal, quando o estudante utiliza o campo de busca.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 3a.1 | Estudante | Digita um termo no campo de busca. |
| 3a.2 | Sistema | Exibe as conquistas correspondentes ao termo informado. |

**Resultado:** O fluxo retorna ao passo 3 do fluxo principal.

## 4. Fluxos de exceção

**Não se aplica.**

*Ponto pendente de refinamento:* o protótipo não representa conquistas ainda não alcançadas, não define o canal de compartilhamento e mantém em aberto se conquistas podem conceder estrelas como recompensa.
