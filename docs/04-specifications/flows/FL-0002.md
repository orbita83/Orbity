# [FL-0002] - Consulta e filtragem de tarefas

## 1. Contexto

**Finalidade do fluxo:** Apresentar as tarefas cadastradas e permitir filtrá-las por estado.

**Objetivo do ator:** Acompanhar as práticas do dia e localizar tarefas pendentes ou concluídas.

## 2. Fluxo principal

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 1 | Estudante | Acessa a aba **Tarefas** na barra de navegação. |
| 2 | Sistema | Exibe a tela **Tarefas** ("Suas práticas do dia") com os filtros **Todos**, **Pendentes** e **Concluídas**, a ação **+ Nova tarefa** e a lista de tarefas, apresentando para cada tarefa o título e a data e hora de término. |
| 3 | Estudante | Seleciona um dos filtros. |
| 4 | Sistema | Atualiza a lista, exibindo apenas as tarefas correspondentes ao filtro selecionado. |

## 3. Fluxos alternativos

**Não se aplica.**

## 4. Fluxos de exceção
