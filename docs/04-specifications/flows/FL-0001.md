# [FL-0001] - Criação de tarefa

## 1. Contexto

**Finalidade do fluxo:** Registrar uma nova tarefa na lista de tarefas do estudante.

**Objetivo do ator:** Cadastrar uma tarefa com título, período de realização e, opcionalmente, descrição e categoria.

## 2. Fluxo principal

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 1 | Estudante | Acessa a aba **Tarefas** na barra de navegação. |
| 2 | Sistema | Exibe a lista de tarefas com a ação **+ Nova tarefa**. |
| 3 | Estudante | Aciona **+ Nova tarefa**. |
| 4 | Sistema | Exibe o formulário **Nova Tarefa** com os campos título da tarefa, descrição (opcional), data e hora de início, data e hora de término e seleção de categoria (opcional). |
| 5 | Estudante | Preenche o título, a data e hora de início e a data e hora de término. |
| 6 | Estudante | Aciona **Criar tarefa**. |
| 7 | Sistema | Registra a tarefa e exibe a mensagem **Tarefa criada!**, informando que a tarefa foi adicionada à lista de tarefas. |
| 8 | Sistema | Apresenta a nova tarefa na lista de tarefas. |

## 3. Fluxos alternativos

### 5a. Preenchimento de campos opcionais

**Ponto de desvio:** passo 5 do fluxo principal, quando o estudante deseja informar uma descrição ou uma categoria.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 5a.1 | Estudante | Informa a descrição da tarefa. |
| 5a.2 | Estudante | Aciona a seleção de categoria e escolhe uma categoria. |

**Resultado:** O fluxo retorna ao passo 6 do fluxo principal.

## 4. Fluxos de exceção

**Não se aplica.**
