# [FL-0006] - Consulta e detalhamento de rotinas

## 1. Contexto

**Finalidade do fluxo:** Apresentar as rotinas cadastradas e o detalhe de cada rotina.

**Objetivo do ator:** Consultar as rotinas e as tarefas que as compõem.

## 2. Fluxo principal

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 1 | Estudante | Acessa a aba **Rotinas** na barra de navegação. |
| 2 | Sistema | Exibe a tela **Rotinas** ("Seus hábitos, todos os dias") com o campo **Buscar rotinas**, a ação **+ Nova rotina** e a lista de rotinas cadastradas. |
| 3 | Estudante | Seleciona uma rotina da lista. |
| 4 | Sistema | Exibe o detalhe da rotina com nome, descrição, a ação **Editar**, a lista **Tarefas da rotina** e o botão **Marcar como concluída**. |

## 3. Fluxos alternativos

### 3a. Busca de rotinas

**Ponto de desvio:** passo 3 do fluxo principal, quando o estudante utiliza o campo **Buscar rotinas**.

| Passo | Ator | Ação |
| ----- | ---- | ---- |
| 3a.1 | Estudante | Digita um termo no campo **Buscar rotinas**. |
| 3a.2 | Sistema | Exibe as rotinas correspondentes ao termo informado. |

**Resultado:** O fluxo retorna ao passo 3 do fluxo principal.

## 4. Fluxos de exceção

**Não se aplica.**
