# [RN-0001] - Vinculação de sessão ativa do modo foco a tarefa ou rotina

## 1. Contexto

O modo foco auxilia o estudante a dedicar atenção a uma atividade específica de estudo ou organização. Esta regra aplica-se sempre que uma sessão do modo foco for iniciada ou mantida ativa no sistema.

## 2. Regra de negócio

Toda sessão ativa do modo foco deve estar obrigatoriamente ligada a uma tarefa ou a uma rotina. Não é permitido iniciar ou manter uma sessão ativa do modo foco sem essa associação.

## 3. Critérios de aceite

- **CA-01:** O sistema deve exigir a seleção de uma tarefa ou de uma rotina para iniciar uma sessão do modo foco.
- **CA-02:** Enquanto a sessão do modo foco estiver ativa, o vínculo com a tarefa ou rotina selecionada deve permanecer registrado e identificável.
- **CA-03:** O sistema deve impedir o início de uma sessão do modo foco quando nenhuma tarefa ou rotina estiver associada.
