# [RN-0010] - Categorias de estudo padrão

## 1. Contexto

O sistema nasce com seis categorias de estudo, para que o estudante possa classificar tarefas e rotinas desde o primeiro uso ([RF-0020](../functional/RF-0020.md)).

## 2. Regra de negócio

As categorias padrão são **Matemática, Leitura, Idiomas, Ciências, Programação e Música**, nessa ordem. Elas são tratadas como as criadas pelo estudante: podem ser renomeadas, trocar de ícone e ser excluídas. Enquanto uma categoria padrão não é renomeada, ela mostra o nome original. Toda instalação, nova ou atualizada, deve ter as seis categorias padrão, e as tarefas e rotinas já salvas com elas continuam válidas, com a mesma categoria.

## 3. Critérios de aceite

- **CA-01:** Uma instalação nova deve começar com as seis categorias padrão, na ordem definida.
- **CA-02:** Uma instalação atualizada de uma versão anterior deve ficar com as seis categorias padrão, sem alterar a categoria das tarefas e o ícone das rotinas já salvas.
- **CA-03:** O estudante deve poder renomear, trocar o ícone e excluir uma categoria padrão.
- **CA-04:** Uma categoria padrão não renomeada deve mostrar o nome original.
