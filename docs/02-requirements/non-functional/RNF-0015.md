# [RNF-0015] - Eficiência no uso de recursos

## 1. Contexto

O sistema deve utilizar os recursos computacionais de forma adequada, evitando consumo desnecessário de memória, processamento, armazenamento ou rede durante o uso normal.

## 2. Detalhamento

As telas e operações devem evitar processamento repetido sem necessidade e carregamento de dados que não sejam necessários à funcionalidade em uso. O consumo deve ser avaliado nos ambientes suportados pelo projeto, considerando operações de tarefas, rotinas e visualização do progresso.

## 3. Critérios de aceite

- **CA-01:** As telas principais devem ser verificadas quanto a consumo excessivo de recursos durante o uso normal.
- **CA-02:** O sistema não deve repetir operações de leitura ou atualização sem necessidade funcional identificada.
- **CA-03:** Quando houver comunicação em rede, as solicitações devem limitar-se aos dados necessários para a operação.
- **CA-04:** Problemas relevantes de consumo identificados em testes devem ser registrados e avaliados para correção.
