# [RNF-0003] - Segurança e privacidade

## 1. Contexto

O sistema deve proteger as informações cadastradas pelo estudante, evitando acesso, alteração ou divulgação não autorizada dos dados relacionados às tarefas, rotinas e ao progresso.

## 2. Detalhamento

As informações manipuladas pelo sistema devem ser tratadas de forma segura durante as operações de cadastro, consulta, edição e exclusão. O sistema deve limitar o acesso às informações de acordo com as permissões efetivamente implementadas e evitar a exposição desnecessária de dados em mensagens, registros técnicos ou telas.

Caso o sistema utilize contas ou múltiplos usuários, cada estudante deve acessar somente os dados para os quais possui autorização.

## 3. Critérios de aceite

- **CA-01:** As operações sobre dados devem respeitar as permissões definidas pelo sistema.
- **CA-02:** Quando houver múltiplos usuários, um usuário não deve conseguir consultar ou modificar dados privados de outro usuário sem autorização.
- **CA-03:** Mensagens de erro e registros técnicos não devem expor senhas, tokens ou outros segredos, caso esses elementos sejam utilizados.
- **CA-04:** Os dados enviados entre cliente e servidor devem utilizar um canal de comunicação protegido quando houver comunicação em rede.
