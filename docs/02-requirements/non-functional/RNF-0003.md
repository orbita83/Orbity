# [RNF-0003] - Acessibilidade

## 1. Contexto

O sistema deve garantir condições de uso equitativas para estudantes com diferentes necessidades visuais e motoras, promovendo inclusão e conformidade com as diretrizes de acessibilidade digital.

## 2. Detalhamento

O aplicativo deve cumprir os parâmetros estabelecidos no documento `design-system/06-acessibilidade.md`, alinhados ao padrão WCAG 2.1 nível AA. Elementos visuais não devem depender exclusivamente de cor para transmitir estados ou informações de progresso. Todos os elementos interativos devem possuir área de toque ergonômica e rótulos acessíveis para tecnologias assistivas (TalkBack no Android, VoiceOver no iOS e leitores de tela na Web).

## 3. Critérios de aceite

- **CA-01:** Os pares de cores entre texto ou ícones essenciais e o fundo devem manter razão de contraste mínima de 4,5:1 para texto normal e 3,0:1 para elementos de grande escala e controles de interface gráfica, conforme as diretrizes do design system.
- **CA-02:** Estados de tarefas (como pendente, concluída e em andamento) e o progresso da constelação devem ser indicados por múltiplos elementos perceptíveis (como texto, ícones ou formatos), e nunca exclusivamente por cor.
- **CA-03:** Todos os controles interativos (botões, seletores, itens de lista e ações de toque) devem possuir área mínima de toque de 48 x 48 dp (ou 44 x 44 pt no iOS).
- **CA-04:** Elementos interativos e campos de entrada devem disponibilizar propriedades de acessibilidade adequadas (`accessibilityLabel`, `accessibilityHint` e `accessibilityRole`), permitindo navegação coerente via leitores de tela.
- **CA-05:** O aplicativo deve suportar o redimensionamento de fontes do sistema operacional sem corte de conteúdo, sobreposição de textos ou perda de funcionalidade.
