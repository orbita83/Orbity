# [RNF-0007] - Integridade dos dados

## 1. Contexto

O sistema deve preservar a correção e a coerência das informações cadastradas, impedindo que operações sobre tarefas, rotinas e progresso gerem dados inválidos ou contraditórios.

## 2. Detalhamento

Os dados devem ser validados antes de serem registrados ou atualizados. Alterações no estado de uma tarefa ou rotina devem refletir-se de maneira coerente nas telas e consultas relacionadas. O sistema também deve impedir que uma mesma ocorrência de progresso seja contabilizada mais de uma vez quando isso contrariar as regras funcionais.

## 3. Critérios de aceite

- **CA-01:** Os campos obrigatórios definidos para cada cadastro devem ser validados antes do registro.
- **CA-02:** Uma edição deve preservar os dados que não foram alterados pelo estudante.
- **CA-03:** O estado apresentado para uma tarefa deve corresponder ao estado registrado.
- **CA-04:** O sistema deve impedir duplicações que violem as regras de registro diário ou de concessão de estrelas.
- **CA-05:** Dados inválidos devem ser rejeitados com indicação compreensível do problema.
