# [RNF-0006] - Compatibilidade e responsividade

## 1. Contexto

O sistema deve funcionar de forma estável e adaptável nas plataformas e dispositivos móveis suportados oficialmente pelo projeto, garantindo legibilidade e usabilidade independentemente da dimensão da tela.

## 2. Detalhamento

O aplicativo deve ser compatível com os ambientes definidos para o ecossistema Expo e React Native do Orbity (Android 8.0+ / API 26+, iOS 14+ e navegadores web modernos). A disposição dos componentes visuais deve se ajustar a diferentes resoluções, densidades de pixels e proporções de tela sem que haja quebra de layout, truncamento de textos essenciais ou sobreposição de controles.

## 3. Critérios de aceite

- **CA-01:** A interface deve se adaptar fluidamente a telas de smartphones de tamanhos variados (a partir de 360 dp de largura) e tablets, sem exibir rolagem horizontal não intencional na tela principal.
- **CA-02:** O aplicativo deve ser executado e atender a todas as funcionalidades principais nas plataformas oficialmente suportadas: Android (versão 8.0 ou superior), iOS (versão 14.0 ou superior) e versões recentes dos navegadores Chrome, Safari e Firefox no ambiente web.
- **CA-03:** Elementos de navegação e botões interativos não devem sobrepor barras de sistema (como navegação por gestos, entalhes ou Dynamic Island), respeitando as áreas seguras (*Safe Area*).
- **CA-04:** Alterações de orientação de tela ou tamanho de janela no ambiente web devem reorganizar o layout de forma imediata e responsiva.
