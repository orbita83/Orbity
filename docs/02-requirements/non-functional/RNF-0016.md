# [RNF-0016] - Clareza das mensagens

## 1. Contexto

O sistema deve comunicar de maneira clara o resultado das ações do estudante e orientar a correção de problemas durante o uso.

## 2. Detalhamento

As mensagens de confirmação, validação, ausência de registros e falha devem utilizar linguagem direta e adequada ao contexto da funcionalidade. A comunicação deve distinguir operações concluídas, operações pendentes e operações que falharam.

## 3. Critérios de aceite

- **CA-01:** Após uma operação concluída com sucesso, o sistema deve fornecer uma indicação clara do resultado.
- **CA-02:** Quando uma operação falhar, a mensagem deve informar que a ação não foi concluída.
- **CA-03:** Mensagens de validação devem indicar como corrigir a entrada inválida, quando aplicável.
- **CA-04:** Estados sem tarefas ou rotinas cadastradas devem apresentar uma mensagem informativa.
- **CA-05:** As mensagens devem evitar termos técnicos desnecessários para o estudante.
