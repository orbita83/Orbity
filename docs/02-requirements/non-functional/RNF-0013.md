# [RNF-0013] - Tratamento de erros

## 1. Contexto

O sistema deve tratar falhas e entradas inválidas de forma compreensível, permitindo que o estudante entenda quando uma operação não pôde ser concluída.

## 2. Detalhamento

Quando ocorrer uma falha de validação, processamento ou comunicação, o sistema deve apresentar uma mensagem apropriada e preservar, sempre que possível, os dados já preenchidos. As mensagens devem evitar detalhes técnicos desnecessários e não devem indicar sucesso quando houver erro.

## 3. Critérios de aceite

- **CA-01:** Entradas inválidas devem gerar uma mensagem que indique o campo ou a informação que precisa ser corrigida.
- **CA-02:** Falhas em operações de cadastro, edição ou exclusão devem ser comunicadas ao estudante.
- **CA-03:** Após uma falha, o sistema não deve apresentar a operação como concluída.
- **CA-04:** Quando for seguro e possível, o sistema deve preservar os dados preenchidos para que o estudante não precise digitá-los novamente.
- **CA-05:** Mensagens exibidas ao estudante não devem expor rastreamentos internos, credenciais ou detalhes sensíveis.
