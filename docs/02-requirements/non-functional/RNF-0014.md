# [RNF-0014] - Persistência dos dados

## 1. Contexto

O sistema deve manter os dados cadastrados e o progresso registrado disponíveis após o encerramento e a reabertura do aplicativo, conforme o mecanismo de armazenamento adotado pelo projeto.

## 2. Detalhamento

As informações de tarefas, rotinas, atividades diárias, sequência e estrelas devem ser armazenadas de forma compatível com as regras funcionais. A persistência deve evitar que os dados desapareçam após uma atualização da interface, navegação entre telas ou reinício do aplicativo.

## 3. Critérios de aceite

- **CA-01:** Tarefas e rotinas registradas devem continuar disponíveis após a navegação entre telas.
- **CA-02:** Após o encerramento e a reabertura do aplicativo, os dados devem permanecer disponíveis conforme a estratégia de armazenamento definida.
- **CA-03:** Alterações confirmadas devem ser preservadas após uma nova consulta.
- **CA-04:** O sistema deve informar quando não for possível salvar ou recuperar dados.
- **CA-05:** O projeto deve documentar qual mecanismo de persistência é utilizado e quais dados ele armazena.
