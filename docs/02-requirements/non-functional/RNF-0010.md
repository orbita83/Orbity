# [RNF-0010] - Compatibilidade

## 1. Contexto

O sistema deve funcionar nos ambientes e navegadores definidos como suportados pelo projeto, mantendo suas funcionalidades principais disponíveis.

## 2. Detalhamento

A interface e as operações devem ser verificadas nos ambientes escolhidos para disponibilização do sistema. Diferenças de navegador, sistema operacional ou tamanho de tela não devem impedir o uso das funcionalidades principais dentro do conjunto de ambientes suportados.

## 3. Critérios de aceite

- **CA-01:** O projeto deve documentar os navegadores, sistemas operacionais e dispositivos oficialmente suportados.
- **CA-02:** As funcionalidades principais devem ser testadas nos ambientes definidos como suportados.
- **CA-03:** Nos ambientes suportados, a interface não deve apresentar erros que impeçam o cadastro, a consulta ou a atualização de tarefas e rotinas.
- **CA-04:** Incompatibilidades conhecidas que afetem o uso devem ser documentadas.
