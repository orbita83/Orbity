# [RNF-0009] - Consistência do progresso e das recompensas

## 1. Contexto

O sistema deve manter consistência entre as atividades registradas, a sequência diária, as estrelas acumuladas e a constelação apresentada ao estudante.

## 2. Detalhamento

As informações de progresso e recompensa devem derivar dos eventos válidos registrados pelo sistema. A sequência diária, a quantidade de estrelas e a representação visual da constelação não devem apresentar valores incompatíveis entre si. O mesmo evento não deve gerar recompensa duplicada.

## 3. Critérios de aceite

- **CA-01:** A sequência apresentada deve corresponder aos registros de atividade diária considerados pelo sistema.
- **CA-02:** Cada evento válido de progresso deve gerar no máximo a recompensa prevista nas regras funcionais.
- **CA-03:** A quantidade de estrelas exibida deve corresponder às estrelas registradas.
- **CA-04:** A constelação deve representar as estrelas efetivamente conquistadas, sem incluir recompensas futuras ou bloqueadas.
- **CA-05:** Após uma atualização de progresso, as informações relacionadas devem apresentar valores coerentes entre si.
