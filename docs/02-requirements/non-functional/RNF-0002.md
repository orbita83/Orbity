# [RNF-0002] - Usabilidade

## 1. Contexto

O sistema deve oferecer uma interface compreensível e consistente, permitindo que o estudante utilize as funcionalidades de gerenciamento de tarefas, organização de rotinas e acompanhamento do progresso diário de maneira intuitiva.

## 2. Detalhamento

A interface deve organizar as informações e os controles de forma clara, facilitando a identificação das funcionalidades disponíveis e a realização das operações. Os elementos de navegação, formulários e ações devem apresentar indicações compreensíveis, reduzindo dificuldades durante a utilização do sistema.

As funcionalidades devem manter padrões de interação consistentes, permitindo que o estudante compreenda como criar, consultar, editar, excluir e concluir tarefas e rotinas, além de visualizar sua sequência diária e suas estrelas acumuladas.

## 3. Critérios de aceite

- **CA-01:** Os elementos de navegação e as ações disponíveis devem possuir identificações claras e compreensíveis.
- **CA-02:** Os formulários de criação e edição devem apresentar indicações que orientem o preenchimento dos campos.
- **CA-03:** O sistema deve apresentar mensagens compreensíveis para informar o resultado das operações realizadas.
- **CA-04:** Quando não houver tarefas ou rotinas cadastradas, o sistema deve apresentar uma indicação de ausência de registros.
- **CA-05:** As funcionalidades que realizam operações semelhantes devem manter padrões de interação consistentes.
