# [RF-0013] - Agendar tarefa

## 1. Contexto

O sistema deve permitir que o estudante agende tarefas, informando datas e horários de início e fim para organizar suas atividades e compromissos. As informações de agendamento são opcionais, permitindo que tarefas sejam cadastradas sem a definição de um período específico.

## 2. Detalhamento

O agendamento de tarefas permite definir um período de realização por meio da seleção de datas e horários de início e término. Essas informações podem ser preenchidas durante a criação ou edição de uma tarefa e, após o registro, ficam disponíveis para consulta. O sistema também permite que tarefas sejam mantidas sem agendamento, possibilitando sua organização independentemente de datas e horários específicos.

## 3. Critérios de aceite

- **CA-01:** O estudante deve conseguir informar a data e o horário de início de uma tarefa.
- **CA-02:** O estudante deve conseguir informar a data e o horário de fim de uma tarefa.
- **CA-03:** O preenchimento das informações de agendamento deve ser opcional.
- **CA-04:** O sistema deve permitir salvar uma tarefa sem informações de agendamento.
- **CA-05:** Após o agendamento bem-sucedido, as informações registradas devem estar disponíveis para consulta.
