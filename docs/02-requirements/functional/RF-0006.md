# [RF-0006] - Reabrir tarefa

## 1. Contexto

O sistema deve permitir que o estudante reabra uma tarefa anteriormente concluída, retornando-a à condição de pendente. Essa funcionalidade possibilita retomar atividades que precisam ser realizadas novamente ou cuja conclusão precisa ser revista.

## 2. Detalhamento

A reabertura de tarefas permite alterar o estado de uma atividade concluída para pendente, por meio de uma ação disponível na interface. Ao reabrir a tarefa, o sistema atualiza seu estado e a transfere da seção de tarefas concluídas para a seção de tarefas pendentes, preservando as informações cadastradas. A tarefa volta a ficar disponível para acompanhamento e poderá ser concluída novamente conforme previsto no RF-0005.

## 3. Critérios de aceite

- **CA-01:** O estudante deve conseguir reabrir uma tarefa concluída.
- **CA-02:** Após a reabertura, a tarefa deve voltar à condição de pendente.
- **CA-03:** A tarefa reaberta deve aparecer na seção de tarefas pendentes.
- **CA-04:** A tarefa reaberta deve deixar de aparecer na seção de tarefas concluídas.
- **CA-05:** O sistema deve preservar as informações da tarefa após sua reabertura.
