# [RF-0010] - Excluir rotina

## 1. Contexto

O sistema deve permitir que o estudante exclua uma rotina previamente cadastrada que não deseja mais manter em sua organização.

## 2. Critérios de aceite

- **CA-01:** O estudante deve conseguir acessar a funcionalidade de exclusão de uma rotina existente.
- **CA-02:** O estudante deve conseguir solicitar a exclusão da rotina selecionada.
- **CA-03:** Após a exclusão bem-sucedida, a rotina não deve mais aparecer entre as rotinas cadastradas.
