# [RF-0009] - Editar rotina

## 1. Contexto

O sistema deve permitir que o estudante edite uma rotina previamente cadastrada, possibilitando atualizar suas informações e as tarefas que a compõem.

## 2. Detalhamento

A edição de rotinas permite modificar as informações de uma rotina existente, incluindo seus dados, as tarefas associadas e os dias programados para sua realização. Ao acessar a funcionalidade, o sistema apresenta as informações atualmente cadastradas para que o estudante realize as alterações desejadas. Após a confirmação, as modificações são armazenadas e disponibilizadas para consulta, mantendo a rotina atualizada conforme a nova configuração.

## 3. Critérios de aceite

- **CA-01:** O estudante deve conseguir acessar a funcionalidade de edição de uma rotina existente.
- **CA-02:** O sistema deve apresentar as informações atuais da rotina.
- **CA-03:** O estudante deve conseguir modificar as informações editáveis da rotina.
- **CA-04:** O estudante deve conseguir alterar as tarefas que compõem a rotina.
- **CA-05:** O estudante deve conseguir confirmar as alterações.
- **CA-06:** Após a atualização bem-sucedida, o sistema deve apresentar as informações atualizadas da rotina.
