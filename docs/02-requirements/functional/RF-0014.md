# [RF-0014] - Registrar atividade diária

## 1. Contexto

O sistema deve registrar os dias em que o estudante concluiu pelo menos uma tarefa ou ocorrência de rotina, permitindo identificar os dias em que houve atividade.

## 2. Detalhamento

O registro de atividade diária permite identificar os dias em que houve conclusão de tarefas ou ocorrências de rotinas. Ao realizar uma dessas atividades, o sistema registra a data correspondente, considerando o horário local do estudante. Esses registros permanecem disponíveis para o acompanhamento da atividade diária e servem como referência para o gerenciamento da sequência de dias consecutivos, conforme previsto no RF-0015.

## 3. Critérios de aceite

- **CA-01:** O sistema deve registrar o dia quando o estudante concluir uma tarefa ou ocorrência de rotina.
- **CA-02:** O sistema deve considerar a data local do estudante para registrar a atividade.
- **CA-03:** O sistema deve contabilizar cada dia apenas uma vez, independentemente da quantidade de atividades concluídas.
- **CA-04:** O registro de atividade do dia deve permanecer válido mesmo quando o estudante desfizer posteriormente a conclusão da tarefa que originou o registro.
