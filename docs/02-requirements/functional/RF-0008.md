# [RF-0008] - Consultar rotinas

## 1. Contexto

O sistema deve permitir que o estudante consulte suas rotinas cadastradas, possibilitando visualizar as atividades organizadas para sua rotina de estudos e compromissos. A consulta deve apresentar as informações da rotina e as tarefas que a compõem.

## 2. Detalhamento

A consulta de rotinas permite visualizar as rotinas cadastradas e acessar suas informações individuais, incluindo as tarefas associadas e os dias programados para sua realização. O estudante pode acompanhar a composição de cada rotina e identificar as atividades que fazem parte de sua programação recorrente.

## 3. Critérios de aceite

- **CA-01:** O estudante deve conseguir acessar suas rotinas cadastradas.
- **CA-02:** O sistema deve apresentar as rotinas disponíveis para consulta.
- **CA-03:** O estudante deve conseguir visualizar as informações de uma rotina.
- **CA-04:** O sistema deve permitir visualizar as tarefas associadas à rotina.
