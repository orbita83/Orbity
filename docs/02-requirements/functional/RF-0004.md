# [RF-0004] - Excluir tarefa

## 1. Contexto

O sistema deve permitir que o estudante exclua tarefas previamente cadastradas que não deseja mais manter em sua organização pessoal.

## 2. Critérios de aceite

- **CA-01:** O estudante deve conseguir acessar a opção de exclusão de uma tarefa existente.
- **CA-02:** O estudante deve conseguir solicitar a exclusão da tarefa selecionada.
- **CA-03:** Após a exclusão bem-sucedida, a tarefa não deve mais aparecer na lista de tarefas cadastradas.
