# [RF-0001] - Criar tarefa

## 1. Contexto

O sistema deve permitir que o estudante crie tarefas para organizar suas atividades pessoais e acadêmicas.

## 2. Detalhamento

A criação de tarefas permite informar título, descrição, prioridade e informações de agendamento. Após a confirmação, o sistema registra a tarefa para posterior consulta.

## 3. Critérios de aceite

- **CA-01:** O estudante deve conseguir acessar a funcionalidade de criação de tarefas.
- **CA-02:** O sistema deve permitir o preenchimento das informações da nova tarefa.
- **CA-03:** O estudante deve conseguir confirmar a criação da tarefa.
- **CA-04:** Após a criação bem-sucedida, a tarefa deve estar disponível para consulta.
