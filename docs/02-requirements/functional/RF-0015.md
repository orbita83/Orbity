# [RF-0015] - Gerenciar sequência diária

## 1. Contexto

O sistema deve gerenciar a sequência de dias consecutivos com atividade registrada.

## 2. Detalhamento

A sequência deve ser calculada com base nos registros de atividade diária do RF-0014, considerando o horário local do estudante e a continuidade entre os dias.

Quando houver interrupção, a sequência será zerada. Uma nova atividade após a interrupção iniciará uma nova sequência.

## 3. Critérios de aceite

- **CA-01:** O sistema deve iniciar a sequência em 1 quando houver o primeiro registro de atividade diária.
- **CA-02:** O sistema deve incrementar a sequência em 1 quando houver um registro de atividade no dia seguinte ao último dia contabilizado.
- **CA-03:** O sistema não deve incrementar a sequência mais de uma vez no mesmo dia.
- **CA-04:** O sistema deve manter a sequência anterior durante o dia seguinte à última atividade, enquanto não houver um novo registro.
- **CA-05:** O sistema deve zerar a sequência quando um dia inteiro terminar sem registro de atividade que mantenha sua continuidade.
- **CA-06:** Ao abrir o aplicativo, o sistema deve verificar os registros diários e atualizar a sequência, considerando eventuais dias sem atividade.
- **CA-07:** Após uma interrupção, o sistema deve reiniciar imediatamente a sequência em 1 quando houver um novo registro de atividade diária.
- **CA-08:** O sistema deve considerar a meia-noite (00h00), no horário local do estudante, como o encerramento do dia.
