# [RF-0005] - Concluir tarefa

## 1. Contexto

O sistema deve permitir que o estudante marque uma tarefa pendente como concluída, possibilitando o acompanhamento das atividades realizadas. Após sua conclusão, a tarefa deve ser apresentada na seção de tarefas concluídas, deixando de aparecer entre as tarefas pendentes.

## 2. Detalhamento

A conclusão de tarefas permite registrar a finalização de uma atividade por meio de uma ação disponível na interface. Ao concluir uma tarefa, o sistema atualiza seu estado e a transfere da seção de tarefas pendentes para a seção de tarefas concluídas, preservando suas informações cadastradas. A tarefa permanece disponível para consulta e poderá ser reaberta posteriormente, conforme previsto no RF-0006.

## 3. Critérios de aceite

- **CA-01:** O estudante deve conseguir marcar uma tarefa pendente como concluída.
- **CA-02:** Após a conclusão, a tarefa deve deixar de aparecer na seção de tarefas pendentes.
- **CA-03:** A tarefa concluída deve ser apresentada na seção de tarefas concluídas.
- **CA-04:** O sistema deve preservar as informações da tarefa após sua conclusão.
