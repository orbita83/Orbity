# [RF-0003] - Editar tarefa

## 1. Contexto

O sistema deve permitir que o estudante edite tarefas previamente cadastradas, possibilitando a atualização de suas informações conforme suas necessidades de organização.

## 2. Critérios de aceite

- **CA-01:** O estudante deve conseguir acessar a funcionalidade de edição de uma tarefa existente.
- **CA-02:** O sistema deve apresentar as informações atuais da tarefa para edição.
- **CA-03:** O estudante deve conseguir modificar as informações editáveis da tarefa.
- **CA-04:** O estudante deve conseguir confirmar as alterações realizadas.
- **CA-05:** Após a atualização bem-sucedida, o sistema deve apresentar as informações atualizadas da tarefa.
