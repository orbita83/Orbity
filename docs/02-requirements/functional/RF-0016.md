# [RF-0016] - Visualizar sequência diária

## 1. Contexto

O sistema deve permitir que o estudante visualize sua sequência atual de dias consecutivos com atividade registrada.

## 2. Detalhamento

A visualização deve apresentar a quantidade atual de dias consecutivos, utilizando a sequência gerenciada pelo RF-0015. O valor apresentado deve corresponder ao estado atualizado da sequência, inclusive quando houver interrupção ou reinício.

## 3. Critérios de aceite

- **CA-01:** O estudante deve conseguir consultar sua sequência diária atual.
- **CA-02:** O sistema deve apresentar a quantidade de dias da sequência gerenciada pelo RF-0015.
- **CA-03:** A informação apresentada deve refletir eventuais alterações na sequência, incluindo interrupções e reinícios.
