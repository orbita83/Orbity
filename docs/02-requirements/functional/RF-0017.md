# [RF-0017] - Desbloquear estrelas

## 1. Contexto

O sistema deve conceder estrelas ao estudante como recompensa pelo aumento de sua sequência diária e pelo desbloqueio de conquistas.

## 2. Detalhamento

A obtenção de estrelas está diretamente relacionada ao progresso do estudante, sendo concedida uma estrela a cada incremento de sua sequência diária, conforme estabelecido no RF-0015, ou a cada nova conquista desbloqueada. O sistema deve registrar e acumular as estrelas recebidas ao longo do tempo, garantindo que cada evento de progresso gere sua respectiva recompensa apenas uma vez.

## 3. Critérios de aceite

- **CA-01:** O sistema deve conceder uma estrela quando a sequência diária do estudante aumentar.
- **CA-02:** O sistema deve conceder uma estrela quando o estudante desbloquear uma conquista.
- **CA-03:** O sistema deve registrar e acumular as estrelas recebidas pelo estudante.
- **CA-04:** O sistema não deve conceder estrelas duplicadas pelo mesmo evento de aumento de sequência ou desbloqueio de conquista.
- **CA-05:** As estrelas recebidas devem permanecer disponíveis para consulta conforme o RF-0018.
