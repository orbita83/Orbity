# [RF-0017] - Desbloquear estrelas

## 1. Contexto

O sistema deve conceder estrelas ao estudante como recompensa pelo aumento de sua sequência diária e pelo desbloqueio de conquistas.

## 2. Detalhamento

A obtenção de estrelas está diretamente relacionada ao progresso do estudante, sendo concedida uma estrela a cada incremento de sua sequência diária, conforme estabelecido no [RF-0015](RF-0015.md), ou a cada nova conquista desbloqueada. O sistema deve registrar e acumular as estrelas recebidas ao longo do tempo por meio de uma chave única de evento (`streak:<AAAA-MM-DD>` para aumentos de sequência e `achievement:<id>` para conquistas), garantindo que cada evento de progresso gere sua respectiva recompensa apenas uma vez.

Pelo princípio de acolhimento e ausência de mecânicas punitivas ([RN-0003](../business-rules/RN-0003.md) CA-02), estrelas concedidas nunca são removidas quando a sequência zera nem quando uma atividade concluída é reaberta. Na transição de esquema para a tabela de estrelas, os dias com atividade já registrados em `daily_activity` recebem retroativamente suas estrelas correspondentes.

## 3. Critérios de aceite

- **CA-01:** O sistema deve conceder uma estrela quando a sequência diária do estudante aumentar.
- **CA-02:** O sistema deve conceder uma estrela quando o estudante desbloquear uma conquista.
- **CA-03:** O sistema deve registrar e acumular as estrelas recebidas pelo estudante em armazenamento local persistente entre aberturas do aplicativo.
- **CA-04:** O sistema não deve conceder estrelas duplicadas pelo mesmo evento de aumento de sequência ou desbloqueio de conquista.
- **CA-05:** As estrelas recebidas devem permanecer disponíveis para consulta conforme o [RF-0018](RF-0018.md) e não devem ser removidas quando a sequência zerar ou quando uma atividade for reaberta.
