# [RF-0007] - Criar rotina

## 1. Contexto

O sistema deve permitir que o estudante crie rotinas para organizar atividades recorrentes. Uma rotina deve possibilitar o agrupamento de tarefas e a definição dos dias da semana em que será realizada.

## 2. Detalhamento

A criação de rotinas permite organizar um conjunto de tarefas em uma programação recorrente. Durante o cadastro, o estudante pode informar os dados da rotina, associar as tarefas que a compõem e definir os dias da semana em que ela será realizada. Após a confirmação, o sistema registra a rotina e a disponibiliza para consulta e acompanhamento de suas ocorrências, conforme a programação estabelecida.

## 3. Critérios de aceite

- **CA-01:** O estudante deve conseguir acessar a funcionalidade de criação de rotinas.
- **CA-02:** O sistema deve permitir informar os dados necessários para criar uma rotina.
- **CA-03:** O estudante deve conseguir associar tarefas à rotina.
- **CA-04:** O estudante deve conseguir confirmar a criação da rotina.
- **CA-05:** Após a criação bem-sucedida, a rotina deve ficar disponível para consulta.
