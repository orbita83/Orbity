# [RF-0020] - Gerenciar categorias de estudo

## 1. Contexto

O sistema deve permitir que o estudante gerencie as categorias de estudo usadas para classificar tarefas e rotinas ([UC-0015](../../04-specifications/use-cases/UC-0015-gerenciar-categorias.md)). Isso preserva a personalização do estudante, que deixa de depender de uma lista fixa.

## 2. Detalhamento

O estudante pode listar, criar, renomear, trocar o ícone e excluir categorias. O sistema oferece seis categorias padrão (Matemática, Leitura, Idiomas, Ciências, Programação e Música), que o estudante trata como qualquer outra categoria ([RN-0010](../business-rules/RN-0010.md)). O nome segue [RN-0008](../business-rules/RN-0008.md) e a exclusão de uma categoria em uso segue [RN-0009](../business-rules/RN-0009.md). O ícone é escolhido numa lista fechada de símbolos do sistema de design (ODS).

## 3. Critérios de aceite

- **CA-01:** O estudante deve conseguir listar as categorias existentes, as padrão e as criadas por ele.
- **CA-02:** O estudante deve conseguir criar uma categoria informando nome e ícone.
- **CA-03:** O estudante deve conseguir renomear uma categoria e trocar o seu ícone.
- **CA-04:** O estudante deve conseguir excluir qualquer categoria, inclusive as padrão ([RN-0010](../business-rules/RN-0010.md)).
- **CA-05:** O sistema não deve aceitar nome inválido nem ícone fora da lista ([RN-0008](../business-rules/RN-0008.md)).
- **CA-06:** As tarefas e rotinas já salvas devem continuar com a mesma categoria depois da atualização do aplicativo ([RN-0010](../business-rules/RN-0010.md)).
