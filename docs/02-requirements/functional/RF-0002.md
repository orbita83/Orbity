# [RF-0002] - Consultar tarefas

## 1. Contexto

O sistema deve permitir que o estudante consulte suas tarefas cadastradas, possibilitando o acompanhamento e a organização de suas atividades.

## 2. Detalhamento

A consulta de tarefas permite visualizar as atividades cadastradas, organizadas de acordo com seu estado de conclusão, distinguindo tarefas pendentes e concluídas. O estudante pode acessar as informações de cada tarefa, como título, descrição, prioridade e agendamento, quando disponíveis. A funcionalidade também deve apresentar uma indicação apropriada quando não houver tarefas para exibição.

## 3. Critérios de aceite

- **CA-01:** O estudante deve conseguir acessar a lista de tarefas cadastradas.
- **CA-02:** O sistema deve apresentar as tarefas disponíveis para consulta.
- **CA-03:** O estudante deve conseguir visualizar as informações de uma tarefa cadastrada.
- **CA-04:** Quando não houver tarefas cadastradas, o sistema deve apresentar um estado vazio informativo.
