# [RF-0011] - Concluir ocorrência de rotina

## 1. Contexto

O sistema deve permitir que o estudante marque como concluída a ocorrência de uma rotina em determinado dia.
A conclusão de uma ocorrência deve representar a realização da rotina naquele dia, sem encerrar ou impedir suas próximas repetições.

## 2. Critérios de aceite

- **CA-01:** O estudante deve conseguir marcar como concluída a ocorrência de uma rotina no dia.
- **CA-02:** O sistema deve registrar a conclusão da ocorrência correspondente.
- **CA-03:** A conclusão de uma ocorrência não deve encerrar a rotina cadastrada.
- **CA-04:** As próximas ocorrências da rotina devem continuar disponíveis conforme os dias definidos para sua repetição.
