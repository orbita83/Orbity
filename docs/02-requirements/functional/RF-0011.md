# [RF-0011] - Concluir ocorrência de rotina

## 1. Contexto

O sistema deve permitir que o estudante marque como concluída a ocorrência de uma rotina em determinado dia. A conclusão de uma ocorrência deve representar a realização da rotina naquele dia, sem encerrar ou impedir suas próximas repetições.

## 2. Detalhamento

A conclusão de uma ocorrência permite registrar a realização de uma rotina em um dia específico, por meio de uma ação disponível na interface. Ao concluir a ocorrência, o sistema atualiza seu estado para concluída, mantendo a rotina cadastrada e disponível para suas próximas execuções, conforme os dias programados.

## 3. Critérios de aceite

- **CA-01:** O estudante deve conseguir marcar como concluída a ocorrência de uma rotina no dia.
- **CA-02:** O sistema deve registrar a conclusão da ocorrência correspondente.
- **CA-03:** A conclusão de uma ocorrência não deve encerrar a rotina cadastrada.
- **CA-04:** As próximas ocorrências da rotina devem continuar disponíveis conforme os dias definidos para sua repetição ([RF-0012](RF-0012.md)), exibindo ao estudante quando a rotina voltará a ficar ativa.
- **CA-05:** Depois de concluída, a ocorrência da rotina não pode ser concluída de novo no mesmo dia. Se o estudante desmarcar a ocorrência, o registro de atividade diária do dia continua valendo ([RF-0014](RF-0014.md), CA-04), e a sequência não muda.
