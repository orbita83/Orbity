# [US-0002] - Visualizar tarefas

## 1. História de usuário

| Campo     | Descrição  |
| --------- | -----------|
| **ID**    | US-0002    |
| **Story** | Eu como estudante quero visualizar minhas tarefas para acompanhar minhas atividades. |

## 2. Critérios de aceite

- **CA-01:** O sistema deve permitir que o estudante visualize suas tarefas cadastradas.
- **CA-02:** O sistema deve exibir o título e a descrição de cada tarefa.
- **CA-03:** O sistema deve permitir que o estudante visualize a data de prazo da tarefa, quando informada.
- **CA-04:** O sistema deve exibir somente as tarefas vinculadas ao estudante autenticado.
- **CA-05:** O sistema deve informar quando não houver tarefas cadastradas.
- **CA-06:** As tarefas devem ser apresentadas de forma organizada para facilitar a consulta.
