# [US-0001] - Criar tarefas

## 1. História de usuário

| Campo     | Descrição |
| --------- | ----------|
| **ID**    | US-0001   |
| **Story** | Eu como estudante quero criar tarefas para organizar minhas atividades pessoais e acadêmicas. |

## 2. Critérios de aceite

- **CA-01:** O sistema deve permitir que o estudante crie uma nova tarefa.
- **CA-02:** O estudante deve poder informar o título e a descrição da tarefa.
- **CA-03:** O sistema deve permitir informar uma data de prazo para a tarefa.
- **CA-04:** Após salvar, a tarefa deve ser exibida na lista de tarefas do estudante.
- **CA-05:** O sistema deve validar os campos obrigatórios antes de salvar a tarefa.
- **CA-06:** As tarefas criadas devem permanecer disponíveis para consulta pelo estudante.
