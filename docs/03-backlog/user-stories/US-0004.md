# [US-0004] - Excluir tarefas

## 1. História de usuário

| Campo     | Descrição |
| --------- | ----------|
| **ID**    | US-0004   |
| **Story** | Eu como estudante quero excluir tarefas para remover atividades que não são mais necessárias. |

## 2. Critérios de aceite

- **CA-01:** O sistema deve permitir que o estudante exclua uma tarefa cadastrada.
- **CA-02:** O sistema deve solicitar a confirmação do estudante antes de excluir a tarefa.
- **CA-03:** Após a confirmação, a tarefa deve ser removida da lista de tarefas do estudante.
- **CA-04:** O sistema deve permitir que o estudante exclua somente suas próprias tarefas.
- **CA-05:** O sistema deve informar quando a tarefa for excluída com sucesso.
- **CA-06:** O sistema deve permitir cancelar a exclusão antes da confirmação.
