# [US-0003] - Editar tarefa

## 1. História de usuário

| Campo     | Descrição                                                                               |
| --------- | --------------------------------------------------------------------------------------- |
| **ID**    | US-0003                                                                                 |
| **Story** | Eu como estudante quero editar minhas tarefas para manter suas informações atualizadas. |

## 2. Critérios de aceite

- **CA-01:** O sistema deve permitir que o estudante edite uma tarefa cadastrada.
- **CA-02:** O estudante deve poder alterar o título e a descrição da tarefa.
- **CA-03:** O sistema deve permitir alterar a data de prazo da tarefa.
- **CA-04:** O sistema deve validar os campos obrigatórios antes de salvar as alterações.
- **CA-05:** Após salvar, o sistema deve apresentar a tarefa com as informações atualizadas.
- **CA-06:** O sistema deve permitir que o estudante edite somente suas próprias tarefas.
